# Full-Featured MERN Stack E-Commerce Platform

A production-ready e-commerce platform built using the MERN stack (MongoDB, Express.js, React, Node.js).

## Architecture

- **`backend/`**: Node.js & Express REST API with MongoDB (Mongoose), JWT authentication, role-based authorization, rate limiting, and product/order management.
- **`frontend/`**: React (Vite) application with modern UI design, state management, product filtering, responsive cart & checkout flow, and admin dashboard.

## Quick Start

### Backend Setup
```bash
cd backend
npm install
cp .env.example .env
npm run dev
```

### Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
